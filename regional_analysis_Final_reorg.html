Abstract

This document is the executable record (Quarto/R) of all analyses reported in the main text. It uses two input files deposited in the repository: ages_kernel_reg_updt.xlsx (dated Acropora palmata fossils) and df_GAM130326.xlsx (centennial climate predictors). From these it reproduces:

  1. binning of fossil ages into 0.1-ka (centennial) intervals, their alignment with climate predictors and the normalization of the response variable;
  2. kernel-density reconstructions of A. palmata age distributions for each reef site and for the regional composite, weighted so that they have the shape of the modelled series;
  3. exploratory analyses of predictor correlation and of abundance across climate-regime combinations;
  4. beta-regression generalized additive models (GAMs) fitted separately to four reef sites (Punta Maroma, Florida, Belize, Saint Croix) and to a regional composite, first with one climate predictor at a time (marginal models) and then as a nested sequence of multi-predictor models, ranked by AIC and Akaike weights;
  5. diagnostics of the selected models (residual plots, concurvity, residual temporal autocorrelation) and sensitivity analyses;
  6. validation and robustness tests of the selected models (cross-validation against an s(age)-only reference model, circular-shift test, drop-one influence).

Code, outputs and a factual description of each result are shown together, so that every value reported in the main text can be traced to the code that produced it. Ecological interpretation is given in the main text.

Normalization

For each site, records are summed per bin (counts). Climate predictors are averaged within the bin, which leaves them unchanged because they are constant within a bin; regime labels are taken from the first record in the bin.

normalize_counts() divides counts by the site maximum (counts_norm, rounded to four decimals). Values exactly 0 or 1 are then transformed as y′ = (y(n − 1) + 0.5)/n, where n is the number of bins in the series (counts_norm_sv); all other values are unchanged. Only bins containing at least one record exist in the series, so no zeros occur and the correction affects only the maximum bin (e.g. 0.984 in Punta Maroma, n = 31).

The response is therefore the relative abundance within bins in which a site is represented. Bins without records are not part of any model: 29 of 60 in Punta Maroma, 33 in Belize, 42 in Saint Croix, 15 in Florida and 2 in the regional pool.

Florida source-standardization

Florida combines records from several source datasets (column source). Therefore, we first sum counts per source and bin, and further divided by each source’s maximum and boundary-corrected. Next we sum the standardized values across sources per bin and normalize as above (datos_fl_std). Consequently, each source has equal weight at its maximum, independent of its number of records.

The regional composite used in every model is the per-bin sum of the four site-level counts_norm_sv series (Florida in its source-standardized form), normalized with the same function (datos_reg, n = 58 bins). Each site therefore enters the composite with its maximum bin equal to one, so its contribution depends on how its records are distributed among bins rather than on its number of records (Section 1.4). The five series are stacked into merged_df_g, which is used by every model and by Figs. 2 and 3a.

normalize_counts <- function(df, panel_name){
  
  df %>%
    mutate(
      counts_norm = round(
        counts / max(counts, na.rm = TRUE),
        4
      ),
      
      counts_norm_sv = ifelse(
        counts_norm %in% c(0,1),
        ((counts_norm * (n() - 1)) + 0.5) / n(),
        counts_norm
      ),
      
      panel = panel_name
    )
  
}

1.4 Acropora palmata age densities (weighted KDE)

Kernel density estimates (KDE) are computed from the individual ages, weighted so that the density has the shape of the modelled series of Section 1.3. Each record receives the weight it carries in counts_norm_sv: in Punta Maroma, Belize and Saint Croix, counts_norm_sv / counts of its bin; in Florida, the product of its source-standardization factor and the Florida normalization factor; in the regional composite, the site weight multiplied by the regional normalization factor. The weights of the records in each bin therefore add up to counts_norm_sv of that bin (checked in the code). For a site with a single source the weights are constant except in the maximum bin, so the weighted KDE has the same shape as the KDE of the raw ages; the weighting changes the shape only for Florida (source standardization) and for the regional composite.

Each density is a Gaussian KDE over 0–6 ka (bandwidth 0.09 ka, 512 points). Its uncertainty is estimated with 1,000 bootstrap resamples of the records with replacement, keeping their weights and stratified by source in Florida and by site in the regional composite. For each resample we keep the density curve and its mean in each 0.1-ka bin. signal_all holds the estimate and the 2.5–97.5 % and 25–75 % bootstrap envelopes of each curve; centennial_density_all holds the bin means of the estimate and their bootstrap SD and 95 % interval.

Because a KDE integrates to one, the regional density distributes a fixed total among the four sites in proportion to the sum of their weights, which depends on how their records are spread among bins, not on how many records they have. Saint Croix, whose 24 records occupy 18 bins with at most two records each, carries 27 % of the regional weight with 9 % of the records, and Punta Maroma 15 % with 25 % of the records (site_share). This is a property of the per-site normalization used in the models, not of the KDE, and it applies equally to the regional GAMs.

## ---- weighted KDE with stratified bootstrap -------------------------------------
## Records are resampled with replacement within strata (sources in Florida, sites in the
## regional composite), keeping their weights. bw = 0.09 ka, 512 points over 0-6 ka.
calc_density_summary <- function(t, w, spot_name, strata = rep(1, length(t)),
                                 B = 1000, bw = 0.09) {
  kde <- function(i) density(t[i], weights = w[i] / sum(w[i]), bw = bw,
                             from = 0, to = 6, n = 512)
  full <- kde(seq_along(t))
  idx  <- split(seq_along(t), strata)
  boot <- t(vapply(seq_len(B), function(b) {
    i <- unlist(lapply(idx, function(ix) ix[sample.int(length(ix), length(ix), replace = TRUE)]))
    kde(i)$y
  }, numeric(512)))

  signal_df <- data.frame(
    x = full$x, estimate = full$y,
    q025 = apply(boot, 2, quantile, 0.025), q975 = apply(boot, 2, quantile, 0.975),
    q25  = apply(boot, 2, quantile, 0.25),  q75  = apply(boot, 2, quantile, 0.75),
    spot = spot_name)

  # centennial summary: estimate and bootstrap SD of the bin-mean density
  bin <- cut(full$x, breaks = breaks, include.lowest = TRUE, right = TRUE)
  bin_mean <- function(y) tapply(y, bin, mean)
  boot_bins <- apply(boot, 1, bin_mean)                 # 60 bins x B
  centennial_summary <- data.frame(
    interval_mid = breaks[-length(breaks)] + 0.05,
    density      = as.numeric(bin_mean(full$y)),
    boot_sd      = apply(boot_bins, 1, sd),
    boot_q025    = apply(boot_bins, 1, quantile, 0.025),
    boot_q975    = apply(boot_bins, 1, quantile, 0.975),
    spot         = spot_name)

  list(signal_df = signal_df, centennial_summary = centennial_summary)
}

3.2. Marginal GAM effects analysis

Relative abundance is continuous and bounded in (0, 1), so we fit GAMs with a beta distribution and logit link (mgcv::gam, family betar). Smoothing parameters are estimated by REML. Continuous predictors enter as thin-plate regression splines (mgcv default, basis dimension k = 10).

Climate regimes enter as factors with reference levels “warmer” (Thermal), “wet” (Hydro) and “low” (Hurricane). Their coefficients are contrasts on the logit scale relative to the reference, conditional on the other terms. Every model includes a smooth of age, s(age), which absorbs temporal structure not attributed to the climate predictor.

Modelling proceeds in two stages: marginal models, with s(age) plus one climate predictor (this section), and combined models, a nested sequence with two branches, one per hurricane metric (Section 3.3).

Candidates are ranked by AIC, ΔAIC and Akaike weights; models within ΔAIC ≤ 2 of the best are considered competitive. Marginal models are fitted without select = TRUE and with k = 10, whereas combined models use select = TRUE and a reduced k; AIC values are therefore not comparable between the two stages.

In this document, “linear” models are those whose climate term is a categorical factor (a parametric term), and “smooth” models those whose climate term is a continuous predictor fitted as a spline.

formulas_mg defines seven marginal candidates, each consisting of s(age) plus one of: s(GMHT_CPS0_30N) (M_temp), s(dT_raw) (M_dt), s(Hur100_fqcy) (M_hf), s(Hur100_av) (M_hav), Thermal (M_the), Hydro (M_hyd) or Hurricane (M_hur). fit_gams_panel() fits all candidates to one panel, and compare_gams() returns AIC, ΔAIC and Akaike weights.

fit_gams_panel <- function(data, formulas) {
  lapply(formulas, function(f)
    gam(f, data = data, family = betar(link = "logit"), method = "REML"))
}

compare_gams <- function(fits) {
  stats <- lapply(fits, AIC)
  df <- data.frame(Model = names(stats), AIC = unlist(stats))
  df <- df %>%
    mutate(deltaAIC = AIC - min(AIC),
           weight = exp(-0.5 * deltaAIC) / sum(exp(-0.5 * deltaAIC)))
  return(df)
}

extract_gam_stats <- function(model, panel, model_type, model_name,
                              alpha = 0.05, p_floor = 1e-4) {
  
  sm <- summary(model)
  av <- anova(model)                       # term-level Wald tests
  
  ## 1. Climate p-values at TERM level (s(age) excluded)
  # Parametric terms: one joint test per factor (all levels together)
  pt_tab <- av$pTerms.table
  p_par  <- if (!is.null(pt_tab) && NROW(pt_tab) > 0)
    setNames(pt_tab[, "p-value"], rownames(pt_tab)) else numeric(0)
  # Smooth terms
  st_tab <- sm$s.table
  st_cl  <- st_tab[rownames(st_tab) != "s(age)", , drop = FALSE]
  p_smo  <- setNames(st_cl[, "p-value"], rownames(st_cl))
  
  p_all  <- c(p_par, p_smo)
  p_all  <- p_all[!is.na(p_all)]
  # mgcv's smooth p-values are approximations; values below ~1e-4 (or slightly
  # negative, from rounding) are not meaningful beyond "very small"
  p_all  <- pmax(p_all, 0)
  
  climate_p   <- if (length(p_all)) min(p_all) else NA_real_
  climate_trm <- if (length(p_all)) names(p_all)[which.min(p_all)] else NA_character_
  sig_terms   <- names(p_all)[p_all < alpha]
  
  ## 2. Significant factor CONTRASTS vs. the reference level (for interpretation)
  ptab  <- sm$p.table
  contr <- ptab[rownames(ptab) != "(Intercept)", , drop = FALSE]
  contr <- contr[!is.na(contr[, 4]) & contr[, 4] < alpha, , drop = FALSE]
  sig_contr <- if (NROW(contr))
    paste0(rownames(contr), " (", sprintf("%.2f", contr[, 1]),
           ", p=", format.pval(contr[, 4], digits = 2, eps = p_floor), ")",
           collapse = "; ") else if (NROW(ptab) <= 1) "n/a (no categorical terms)" else "none"
  
  data.frame(
    Panel             = panel,
    Type              = model_type,
    Model             = model_name,
    AIC               = round(AIC(model), 3),
    DevianceExplained = round(sm$dev.expl, 3),
    R2_Adj            = round(sm$r.sq, 3),
    ClimateTerm       = climate_trm,
    Climate_p         = climate_p,
    Climate_p_label   = if (is.na(climate_p)) "NA" else
      format.pval(climate_p, digits = 2, eps = p_floor),
    SignificantTerms  = if (length(sig_terms)) paste(sig_terms, collapse = "; ")
    else "Not significant",
    SignificantContrasts = sig_contr,
    EDF_Terms         = paste0(rownames(st_tab), " (EDF=",
                               round(st_tab[, "edf"], 2), ")", collapse = "; "),
    Inference         = ifelse(!is.na(climate_p) && climate_p < alpha,
                               "Supported", "Weak support"),
    stringsAsFactors  = FALSE
  )
}

3.3.2 Fitting procedure (ΔAIC and Akaike weights)

fit_combined_gams_safe() fits the eleven candidates to each panel in six steps:

  1. It removes rows with missing or infinite numeric values.

  2. It skips a model if n < 8 or n ≤ 3 × (number of smooths).

  3. It sets a common basis dimension for all smooths of a model, k = max(3, min(10, ⌊(n − 1)/number of smooths⌋)). For the four-smooth models this gives k = 7 in Punta Maroma (n = 31), 6 in Belize (27), 4 in Saint Croix (18), and 10 in Florida (45) and the regional composite (58). Nested models within a panel therefore do not share the same basis size (e.g. in Punta Maroma M1 uses k = 10 and M4 uses k = 7).

  4. It fits gam() (betar, REML) with select = TRUE, which penalizes each smooth’s null space so that a term can be shrunk to EDF ≈ 0. (bam() is used only when n > 100, which does not occur here.)

  5. If the beta fit fails, it refits the model as quasibinomial; such a model has no AIC and is excluded from the ranking.

  6. It excludes rank-deficient fits, i.e. models whose model-matrix rank is lower than the number of coefficients because two parametric terms are aliased. The names of the excluded models are returned in $excluded.

The function returns AIC, deviance explained, adjusted R², total EDF, ΔAIC and Akaike weights for each retained model; ΔAIC and weights are computed over the retained candidates only.

Excluded candidates. Because the thermal, hydroclimatic and hurricane regimes are defined on the same regional chronology and each site covers only part of the 60 bins, some regime levels are nested within others at site level:

  • In Florida, Belize and Saint Croix, the “medium” hurricane regime occurs only within the CWP&MWA thermal regime, so M7_fqcy and M7_av are excluded.

  • In Punta Maroma, the “cooler” thermal regime coincides with the wet and dry hydroclimatic states (all LIA and “warmer” bins are “variable”), so M6 and M7 of both branches are excluded.

  • No candidate is excluded in the regional composite.

Consequently, the number of candidates compared is 7 in Punta Maroma, 9 in Florida, Belize and Saint Croix, and 11 in the regional composite.

  max(3, min(10, floor((n_obs - 1) / max(1, n_smooth_terms))))
}

fit_combined_gams_safe <- function(formulas_cb, data, segment_name) {
  
  data_clean <- data %>%
    mutate(across(where(is.numeric), ~replace(., is.infinite(.), NA))) %>%
    drop_na()
  
  n_obs <- nrow(data_clean)
  
  fits <- lapply(names(formulas_cb), function(name) {
    f <- formulas_cb[[name]]
    n_smooth <- count_smooth_terms(f)
    if (n_obs < 8 || n_obs <= n_smooth * 3) {
      message(paste("Skipping model", name, "for", segment_name,
                    "- insufficient observations (n =", n_obs, ") for",
                    n_smooth, "smooth term(s)"))
      return(NULL)
    }
    
    k_max <- safe_k_for(n_obs, n_smooth)
    f_safe <- if (n_smooth > 0) cap_smooth_k(f, k_max) else f
    
    tryCatch({
      m <- if (n_obs > 100) {
        bam(f_safe, data = data_clean, family = betar(link = "logit"),
            method = "fREML", select = TRUE, discrete = TRUE)
      } else {
        gam(f_safe, data = data_clean,
            family = betar(link = "logit"), method = "REML",
            select = TRUE)
      }
      environment(m$formula) <- environment()
      m
    }, error = function(e) {
      message(paste("Model", name, "fail in", segment_name,
                    "using betar:", e$message, "→ testing quasibinomial"))
      tryCatch({
        m2 <- gam(f_safe, data = data_clean,
                  family = quasibinomial(link = "logit"), method = "REML",
                  select = TRUE)
        environment(m2$formula) <- environment()
        m2
      }, error = function(e2) {
        message(paste("Model", name, "also failed with quasibinomial in", segment_name, ":", e2$message))
        return(NULL)
      })
    })
  })
  names(fits) <- names(formulas_cb)
  
  fits <- fits[!sapply(fits, is.null)]
  
 rank_def <- vapply(fits, function(m) m$rank < length(coef(m)), logical(1))
  excluded <- names(fits)[rank_def]
  if (length(excluded)) {
    message("Excluded as rank-deficient in ", segment_name, ": ",
            paste(excluded, collapse = ", "))
    fits <- fits[!rank_def]
  }
  
  stats <- lapply(names(fits), function(name) {
    m <- fits[[name]]
    s <- summary(m)
    data.frame(
      Model = name,
      AIC = tryCatch(AIC(m), error = function(e) NA),
      DevianceExplained = s$dev.expl,
      R2_Adj = s$r.sq,
      EDF = sum(m$edf),
      Segment = segment_name,
      stringsAsFactors = FALSE
    )
  })
  
  stats_df <- bind_rows(stats)
  
  if (nrow(stats_df) > 0) {
    
    stats_df <- stats_df %>%
      mutate(
        deltaAIC = AIC - min(AIC, na.rm = TRUE),
        weight = exp(-0.5 * deltaAIC) /
          sum(exp(-0.5 * deltaAIC), na.rm = TRUE)
      ) %>%
      arrange(AIC)
    
  }
  
  if (nrow(stats_df) > 0) {
    p_delta <- ggplot(stats_df, aes(x = reorder(Model, deltaAIC), y = deltaAIC)) +
      geom_col(fill = "steelblue") +
      geom_hline(yintercept = 2, linetype = "dashed", color = "red") +
      coord_flip() +
      labs(title = paste("ΔAIC by model -", segment_name),
           subtitle = "Dashed line = ΔAIC = 2 (competitive threshold)",
           x = "Model", y = "ΔAIC") +
      theme_minimal() +
      theme(legend.position = "bottom")
    
    p_weight <- ggplot(stats_df, aes(x = reorder(Model, -weight), y = weight)) +
      geom_col(fill = "darkgreen") +
      coord_flip() +
      labs(title = paste("AIC weights by model -", segment_name),
           subtitle = "Relative probability each model is best",
           x = "Model", y = "AIC weight") +
      theme_minimal()
    
    plots <- list(delta = p_delta, weight = p_weight)
  } else {
    plots <- NULL
  }
  
  return(list(fits = fits, stats = stats_df, plots = plots,
              excluded = excluded))  
}

extract_combined_stats <- function(best_obj, panel_name,
                                   alpha = 0.05, p_floor = 1e-4) {
  
  fmt_p <- function(p) ifelse(p < p_floor, "<1e-04", sprintf("%.2g", p))
  
  model <- best_obj$fit
  sm    <- summary(model)
  av    <- anova(model)
  
  ## Term-level p-values (s(age) excluded)
  pt_tab <- av$pTerms.table
  p_par  <- if (!is.null(pt_tab) && NROW(pt_tab) > 0)
    setNames(pt_tab[, "p-value"], rownames(pt_tab)) else numeric(0)
  st_tab <- sm$s.table
  st_cl  <- st_tab[rownames(st_tab) != "s(age)", , drop = FALSE]
  p_smo  <- setNames(st_cl[, "p-value"], rownames(st_cl))
  
  p_all  <- c(p_par, p_smo)
  p_all  <- pmax(p_all[!is.na(p_all)], 0)
  sig    <- p_all[p_all < alpha]
  
  sig_terms <- if (length(sig))
    paste0(names(sig), " (p=", fmt_p(sig), ")",
           collapse = "; ") else "Not significant"
  climate_p <- if (length(p_all)) min(p_all) else NA_real_
  
ptab  <- sm$p.table
  contr <- ptab[rownames(ptab) != "(Intercept)", , drop = FALSE]
  contr <- contr[!is.na(contr[, 4]) & contr[, 4] < alpha, , drop = FALSE]
  sig_contr <- if (NROW(contr))
    paste0(rownames(contr), " (", sprintf("%.2f", contr[, 1]),
           ", p=", fmt_p(contr[, 4]), ")",
           collapse = "; ") else if (NROW(ptab) <= 1) "n/a (no categorical terms)" else "none"
  
  data.frame(
    Panel                = panel_name,
    Model                = best_obj$best_model,
    AIC                  = round(AIC(model), 3),
    DevianceExplained    = round(sm$dev.expl, 3),
    R2_Adj               = round(sm$r.sq, 3),
    SignificantTerms     = sig_terms,
    Climate_p            = climate_p,
    Climate_p_label      = if (is.na(climate_p)) "NA" else
      fmt_p(climate_p),
    SignificantContrasts = sig_contr,
    EDF_Terms            = paste0(rownames(st_tab), " (EDF=",
                                  round(st_tab[, "edf"], 2), ")", collapse = "; "),
    stringsAsFactors     = FALSE
  )
}

}

check_temporal_independence <- function(mod) {
  # Extraer residuales tipo pearson
  res_raw <- residuals(mod, type = "pearson")
  if (is.list(res_raw)) res_raw <- unlist(res_raw)
  res_raw <- as.numeric(res_raw)
  
  # AR(1) coeficiente
  phi <- cor(res_raw[-1], res_raw[-length(res_raw)])
  
  # Durbin–Watson
  dw <- lmtest::dwtest(res_raw ~ 1)
  
  # Ljung–Box
  lb <- Box.test(res_raw, lag = 10, type = "Ljung-Box")
  
  list(
    phi_AR1 = phi,
    DW_stat = dw$statistic,
    DW_pval = dw$p.value,
    LB_stat = lb$statistic,
    LB_pval = lb$p.value,
    res_raw = res_raw
  )
}

4.5 Sensitivity analyses

We test the main results of the selected combined models against four alternative analyses:

  1. Residual autocorrelation (Florida, Punta Maroma). The two panels with positive lag-1 autocorrelation (Section 4.4) are refitted as Gaussian GAMMs on the logit of the response, with the same terms and basis dimensions, first with independent errors and then with a continuous-time AR(1) structure (corCAR1 on age, because bins are not always consecutive). mgcv does not provide a beta family with correlated errors, so this is an approximation used as a check, not a replacement for the beta models.
  2. Florida source standardization. The combined and marginal candidate sets are refitted to the Florida series pooled across sources (datos_fl_norm, Section 3.1.1).
  3. Saint Croix response. Because the response takes only two values, the selected model is refitted as a binomial GAM of one versus two records per bin.
  4. Thermal regime in Punta Maroma. The M6 and M7 candidates were excluded as rank-deficient in this panel, so the thermal regime is added directly to the selected hurricane model.

ar1_check <- function(site, dat, term) {
  d  <- dat %>% arrange(age) %>%
    mutate(ly = qlogis(pmin(pmax(counts_norm_sv, 1e-4), 1 - 1e-4)))
  f  <- update(formula(best_models[[site]]), ly ~ .)
  m0 <- gamm(f, data = d, method = "REML")
  m1 <- gamm(f, data = d, method = "REML", correlation = corCAR1(form = ~ age))
  lrt <- anova(m1$lme, m0$lme)
  phi <- coef(m1$lme$modelStruct$corStruct, unconstrained = FALSE)
  tibble::tibble(
    Check = "Residual AR(1) (Gaussian GAMM on logit, corCAR1)", Panel = site, Term = term,
    Reference = fmt_p2(sm_p(best_models[[site]], term)),

}

4.6 Predictive validation and robustness of the coral–climate associations

Every model includes s(age), which represents the temporal structure of each series: the long-term trend and low-frequency variation in abundance, including taphonomic and sampling effects that cannot be separated from ecological change. Climatic effects are therefore estimated conditional on s(age). All analyses in this section compare the selected models with a reference model, counts_norm_sv ~ s(age), and so ask whether climate adds information beyond the temporal structure of the coral record.

For each panel we evaluate three models: the reference model, the best marginal model (lowest AIC, Section 3.2) and the selected combined model (Section 3.3). Four analyses are run:

  1. Cross-validation. Each century is left out in turn, the model is refitted to the remaining centuries and the left-out century is predicted (leave-one-out, LOO). In a second version, the centuries within ±200 years of the left-out one are also removed from the fitting data (h-block), so that the prediction cannot borrow information from immediately adjacent centuries. Predictions are scored by their log-likelihood under the fitted beta distribution, and each model is compared with the reference model through the summed difference (ΔELPD; positive = better than the reference), its standard error and the percentage of centuries predicted better than by the reference.
  2. Circular-shift test. The complete 60-bin climatic series (all predictors together) is rotated in time by 6–54 bins (600–5,400 years; 49 shifts) relative to the coral record, while the response and s(age) stay fixed. Rotation keeps the shape and autocorrelation of both series and the correlations among predictors, and destroys only their alignment. The statistic is the AIC improvement over the reference model; p = (1 + number of shifts with an improvement ≥ the observed one) / (1 + number of shifts). The smallest attainable p is 0.02. Shifts of ≤ 500 years are excluded because neighbouring centuries are autocorrelated.
  3. Drop-one influence. Each century is removed in turn and the model refitted. For every climatic term we report its p-value with all data, the largest p-value across the drop-one fits, the century whose removal gives that largest value and the percentage of drop-one fits in which the term stays significant (p < 0.05).
  4. Former cross-validation (withdrawn). The five-fold cross-validation of the first revision is re-run to document why it was withdrawn (see below).

During refitting the basis dimension of each smooth is capped with safe_k_for() from the number of fitting observations, and further reduced if the total number of coefficients would reach that number. A refit is skipped, and the left-out century counted as not predicted, when the fitting data do not contain every level of a categorical predictor or the categorical design is rank-deficient. For panels with at least 21 observations the full-data fits are identical to those of Sections 3.2–3.3. In Saint Croix (n = 18) the marginal smooths use k = 8 instead of the default 10, which changes the AIC of the marginal model by less than 0.01.

fac_vars <- c("Thermal", "Hydro", "Hurricane")

# refit a model to a subset with the k cap and the rank / coefficient guards
fit_val <- function(f, d, combined) {
  ns <- count_smooth_terms(f)
  for (v in intersect(fac_vars, all.vars(f))) d[[v]] <- droplevels(d[[v]])
  fv <- intersect(fac_vars, all.vars(f)); n_par <- 1
  if (length(fv)) {
    X <- tryCatch(model.matrix(reformulate(fv), d), error = function(e) NULL)
    if (is.null(X) || qr(X)$rank < ncol(X)) return(NULL)
    n_par <- ncol(X)
  }
  if (ns > 0) {
    k <- safe_k_for(nrow(d), ns)
    while (k > 3 && n_par + ns * (k - 1) >= nrow(d)) k <- k - 1
    if (n_par + ns * (k - 1) >= nrow(d)) return(NULL)
    f <- cap_smooth_k(f, k)
  }
  tryCatch(suppressWarnings(gam(f, data = d, family = betar(link = "logit"),
                                method = "REML", select = combined)),
           error = function(e) NULL)
}

lpd_val <- function(m, test) {
  if (is.null(m)) return(rep(NA_real_, nrow(test)))
  for (v in intersect(fac_vars, all.vars(formula(m))))
    if (any(!as.character(test[[v]]) %in% as.character(unique(m$model[[v]]))))
      return(rep(NA_real_, nrow(test)))
  mu  <- as.numeric(predict(m, newdata = test, type = "response"))
  phi <- m$family$getTheta(TRUE)
  dbeta(test$counts_norm_sv, mu * phi, (1 - mu) * phi, log = TRUE)
}

pointwise_cv <- function(f, d, combined, buffer = 0) {
  sapply(seq_len(nrow(d)), function(i) {
    drop <- if (buffer > 0) which(abs(d$age - d$age[i]) <= buffer + 1e-9) else i
    lpd_val(fit_val(f, d[-drop, ], combined), d[i, , drop = FALSE])
  })
}
