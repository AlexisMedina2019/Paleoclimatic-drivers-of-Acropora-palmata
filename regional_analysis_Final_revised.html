Abstract

This document is the executable record (Quarto/R) of all analyses reported in the main text. It uses two input files deposited in the repository: ages_kernel_reg_updt.xlsx (dated Acropora palmata fossils) and df_GAM130326.xlsx (centennial climate predictors). From these it reproduces:

  1. kernel-density reconstructions of A. palmata age distributions for each reef site and for all records pooled;
  2. binning of fossil ages into 0.1-ka (centennial) intervals and their alignment with climate predictors;
  3. exploratory analyses of predictor correlation and of abundance across climate-regime combinations;
  4. beta-regression generalized additive models (GAMs) fitted separately to four reef sites (Punta Maroma, Florida, Belize, Saint Croix) and to a regional composite, first with one climate predictor at a time (marginal models) and then as a nested sequence of multi-predictor models, ranked by AIC and Akaike weights;
  5. diagnostics of the selected models (residual plots, concurvity, residual temporal autocorrelation).

Code, outputs and a factual description of each result are shown together, so that every value reported in the main text can be traced to the code that produced it. Ecological interpretation is given in the main text.

REGIONAL ACROPORA PALMATA ANALYSIS

We import the fossil chronology (ages_kernel_reg_updt.xlsx) and retain A. palmata records (group == "palmata") dated 0–6 ka.

The function calc_density_summary() estimates the age distribution of a set of records by repeated subsampling. In each of 1,000 iterations it draws min(40, n) records without replacement and computes a Gaussian kernel density estimate over 0–6 ka (bandwidth 0.09 ka, 512 grid points). Across iterations it stores the pointwise median density and the 2.5–97.5 % and 25–75 % quantile envelopes (signal_df).

The median curve is then summarized by 0.1-ka bins. avg_median is the mean of the median density over the grid points falling in each bin. sd_median and se_median describe how much the median curve varies within the bin; they are not measures of sampling uncertainty across iterations.

The function is applied to each site and to all records pooled (“Regional (All spots)”), yielding signal_all (density curves) and centennial_density_all (centennial summaries).

Two properties of this procedure affect interpretation:

  1. Envelopes are degenerate for small sites. Because each iteration draws 40 records without replacement, every iteration uses all records for Saint Croix (n = 24), and all but one for Belize (n = 41). The envelopes therefore reflect subsampling variability only for Punta Maroma (n = 64), Florida (n = 128) and the pooled regional set (n = 257).
  2. The pooled curve is weighted toward Florida, which contributes 128 of the 257 records. It differs from the regional composite used in the GAMs (Section 3.1.1), in which each site is weighted equally.

calc_density_summary <- function(df, spot_name){
  df$t_ka <- as.numeric(df$t_ka)
  
signalmx <- matrix(ncol = 512, nrow = 1000)
  for(i in 1:nrow(signalmx)){
    signalmx[i,] <- density(df$t_ka[sample(1:nrow(df), min(40, nrow(df)))],
                            bw = 0.09, from = 0, to = 6)$y
  }
  
  x <- seq(0, 5.999, length.out = 512)   
  
signal_df <- data.frame(
    x      = x,
    q025   = apply(signalmx, 2, quantile, 0.025),
    q975   = apply(signalmx, 2, quantile, 0.975),
    q25    = apply(signalmx, 2, quantile, 0.25),
    q75    = apply(signalmx, 2, quantile, 0.75),
    median = apply(signalmx, 2, median),
    spot   = spot_name
  )
  
 breaks <- seq(0, 6, by = 0.1)
  mids   <- breaks[-length(breaks)] + diff(breaks)/2
  
  centennial_summary <- signal_df %>%
    mutate(interval = cut(x, breaks = breaks, include.lowest = TRUE, right = TRUE)) %>%
    group_by(interval) %>%
    summarise(
      avg_median = mean(median, na.rm = TRUE),
      sd_median  = sd(median, na.rm = TRUE),
      n_obs      = n(),
      .groups = "drop"
    ) %>%
    mutate(
      se_median    = sd_median / sqrt(n_obs),
      interval_mid = mids[as.numeric(interval)],
      spot         = spot_name
    )
  
  return(list(signal_df = signal_df, centennial_summary = centennial_summary))
}

3.1.1 Response variable normalization

For each site, records are summed per bin (counts). Climate predictors are averaged within the bin, which leaves them unchanged because they are constant within a bin; regime labels are taken from the first record in the bin.

normalize_counts() divides counts by the site maximum (counts_norm, rounded to four decimals). Values exactly 0 or 1 are then transformed as y′ = (y(n − 1) + 0.5)/n, where n is the number of bins in the series (counts_norm_sv); all other values are unchanged. Only bins containing at least one record exist in the series, so no zeros occur and the correction affects only the maximum bin (e.g. 0.984 in Punta Maroma, n = 31).

The response is therefore the relative abundance within bins in which a site is represented. Bins without records are not part of any model: 29 of 60 in Punta Maroma, 33 in Belize, 42 in Saint Croix, 15 in Florida and 2 in the regional pool.

a. Florida source-standardization

Florida combines records from several source datasets (column source). Therefore, we first sum counts per source and bin, and further divided by each source’s maximum and boundary-corrected. Next we sum the standardized values across sources per bin and normalize as above (datos_fl_std). Consequently, each source has equal weight at its maximum, independent of its number of records.

The regional composite used in every model is the per-bin sum of the four site-level counts_norm_sv series (Florida in its source-standardized form), normalized with the same function (datos_reg, n = 58 bins). Each site contributes equally; this differs from the pooled “Regional” series of Figs. 2 and 3a, in which Florida records dominate. The five series are stacked into merged_df_g.

normalize_counts <- function(df, panel_name){
  
  df %>%
    mutate(
      counts_norm = round(
        counts / max(counts, na.rm = TRUE),
        4
      ),
      
      counts_norm_sv = ifelse(
        counts_norm %in% c(0,1),
        ((counts_norm * (n() - 1)) + 0.5) / n(),
        counts_norm
      ),
      
      panel = panel_name
    )
  
}

3.2. Marginal GAM effects analysis

Relative abundance is continuous and bounded in (0, 1), so we fit GAMs with a beta distribution and logit link (mgcv::gam, family betar). Smoothing parameters are estimated by REML. Continuous predictors enter as thin-plate regression splines (mgcv default, basis dimension k = 10).

Climate regimes enter as factors with reference levels “warmer” (Thermal), “wet” (Hydro) and “low” (Hurricane). Their coefficients are contrasts on the logit scale relative to the reference, conditional on the other terms. Every model includes a smooth of age, s(age), which absorbs temporal structure not attributed to the climate predictor.

Modelling proceeds in two stages: marginal models, with s(age) plus one climate predictor (this section), and combined models, a nested sequence with two branches, one per hurricane metric (Section 3.3).

Candidates are ranked by AIC, ΔAIC and Akaike weights; models within ΔAIC ≤ 2 of the best are considered competitive. Marginal models are fitted without select = TRUE and with k = 10, whereas combined models use select = TRUE and a reduced k; AIC values are therefore not comparable between the two stages.

In this document, “linear” models are those whose climate term is a categorical factor (a parametric term), and “smooth” models those whose climate term is a continuous predictor fitted as a spline.

fit_gams_panel <- function(data, formulas) {
  lapply(formulas, function(f)
    gam(f, data = data, family = betar(link = "logit"), method = "REML"))
}

compare_gams <- function(fits) {
  stats <- lapply(fits, AIC)
  df <- data.frame(Model = names(stats), AIC = unlist(stats))
  df <- df %>%
    mutate(deltaAIC = AIC - min(AIC),
           weight = exp(-0.5 * deltaAIC) / sum(exp(-0.5 * deltaAIC)))
  return(df)
}

Contrasts are relative to the reference levels warmer / wet / low. p-values below 10⁻⁴ are reported as “<1e-04”, the precision limit of mgcv’s approximation for smooth terms.

  av <- anova(model)                       # term-level Wald tests
  
  ## 1. Climate p-values at TERM level (s(age) excluded)
  # Parametric terms: one joint test per factor (all levels together)
  pt_tab <- av$pTerms.table
  p_par  <- if (!is.null(pt_tab) && NROW(pt_tab) > 0)
    setNames(pt_tab[, "p-value"], rownames(pt_tab)) else numeric(0)
  # Smooth terms
  st_tab <- sm$s.table
  st_cl  <- st_tab[rownames(st_tab) != "s(age)", , drop = FALSE]
  p_smo  <- setNames(st_cl[, "p-value"], rownames(st_cl))
  
  p_all  <- c(p_par, p_smo)
  p_all  <- p_all[!is.na(p_all)]
  # mgcv's smooth p-values are approximations; values below ~1e-4 (or slightly
  # negative, from rounding) are not meaningful beyond "very small"
  p_all  <- pmax(p_all, 0)
  
  climate_p   <- if (length(p_all)) min(p_all) else NA_real_
  climate_trm <- if (length(p_all)) names(p_all)[which.min(p_all)] else NA_character_
  sig_terms   <- names(p_all)[p_all < alpha]
  
  ## 2. Significant factor CONTRASTS vs. the reference level (for interpretation)
  ptab  <- sm$p.table
  contr <- ptab[rownames(ptab) != "(Intercept)", , drop = FALSE]
  contr <- contr[!is.na(contr[, 4]) & contr[, 4] < alpha, , drop = FALSE]
  sig_contr <- if (NROW(contr))
    paste0(rownames(contr), " (", sprintf("%.2f", contr[, 1]),
           ", p=", format.pval(contr[, 4], digits = 2, eps = p_floor), ")",
           collapse = "; ") else "none"
  
  data.frame(
    Panel             = panel,
    Type              = model_type,
    Model             = model_name,
    AIC               = round(AIC(model), 3),
    DevianceExplained = round(sm$dev.expl, 3),
    R2_Adj            = round(sm$r.sq, 3),
    ClimateTerm       = climate_trm,
    Climate_p         = climate_p,
    Climate_p_label   = if (is.na(climate_p)) "NA" else
      format.pval(climate_p, digits = 2, eps = p_floor),
    SignificantTerms  = if (length(sig_terms)) paste(sig_terms, collapse = "; ")
    else "Not significant",
    SignificantContrasts = sig_contr,
    EDF_Terms         = paste0(rownames(st_tab), " (EDF=",
                               round(st_tab[, "edf"], 2), ")", collapse = "; "),
    Inference         = ifelse(!is.na(climate_p) && climate_p < alpha,
                               "Supported", "Weak support"),
    stringsAsFactors  = FALSE
  )
}

3.3.2 Fitting procedure (ΔAIC and Akaike weights)

fit_combined_gams_safe() fits the eleven candidates to each panel in six steps:

  1. It removes rows with missing or infinite numeric values.

  2. It skips a model if n < 8 or n ≤ 3 × (number of smooths).

  3. It sets a common basis dimension for all smooths of a model, k = max(3, min(10, ⌊(n − 1)/number of smooths⌋)). For the four-smooth models this gives k = 7 in Punta Maroma (n = 31), 6 in Belize (27), 4 in Saint Croix (18), and 10 in Florida (45) and the regional composite (58). Nested models within a panel therefore do not share the same basis size (e.g. in Punta Maroma M1 uses k = 10 and M4 uses k = 7).

  4. It fits gam() (betar, REML) with select = TRUE, which penalizes each smooth’s null space so that a term can be shrunk to EDF ≈ 0. (bam() is used only when n > 100, which does not occur here.)

  5. If the beta fit fails, it refits the model as quasibinomial; such a model has no AIC and is excluded from the ranking.

  6. It excludes rank-deficient fits, i.e. models whose model-matrix rank is lower than the number of coefficients because two parametric terms are aliased. The names of the excluded models are returned in $excluded.

The function returns AIC, deviance explained, adjusted R², total EDF, ΔAIC and Akaike weights for each retained model; ΔAIC and weights are computed over the retained candidates only.

Excluded candidates. Because the thermal, hydroclimatic and hurricane regimes are defined on the same regional chronology and each site covers only part of the 60 bins, some regime levels are nested within others at site level:

  • In Florida, Belize and Saint Croix, the “medium” hurricane regime occurs only within the CWP&MWA thermal regime, so M7_fqcy and M7_av are excluded.

  • In Punta Maroma, the “cooler” thermal regime coincides with the wet and dry hydroclimatic states (all LIA and “warmer” bins are “variable”), so M6 and M7 of both branches are excluded.

  • No candidate is excluded in the regional composite.

Consequently, the number of candidates compared is 7 in Punta Maroma, 9 in Florida, Belize and Saint Croix, and 11 in the regional composite.

count_smooth_terms <- function(formula) {
  lengths(regmatches(paste(deparse(formula, width.cutoff = 500L), collapse = " "),
                      gregexpr("s\\(", paste(deparse(formula, width.cutoff = 500L), collapse = " "))))
}

cap_smooth_k <- function(formula, k_max, env = parent.frame()) {
  f_chr <- paste(deparse(formula, width.cutoff = 500L), collapse = " ")
  f_chr <- gsub("s\\(\\s*([A-Za-z0-9_\\.]+)\\s*\\)",
                paste0("s(\\1, k = ", k_max, ")"), f_chr)
  as.formula(f_chr, env = env)
}

safe_k_for <- function(n_obs, n_smooth_terms) {
  max(3, min(10, floor((n_obs - 1) / max(1, n_smooth_terms))))
}

fit_combined_gams_safe <- function(formulas_cb, data, segment_name) {
  
  data_clean <- data %>%
    mutate(across(where(is.numeric), ~replace(., is.infinite(.), NA))) %>%
    drop_na()
  
  n_obs <- nrow(data_clean)
  
  fits <- lapply(names(formulas_cb), function(name) {
    f <- formulas_cb[[name]]
    n_smooth <- count_smooth_terms(f)
    if (n_obs < 8 || n_obs <= n_smooth * 3) {
      message(paste("Skipping model", name, "for", segment_name,
                    "- insufficient observations (n =", n_obs, ") for",
                    n_smooth, "smooth term(s)"))
      return(NULL)
    }
    
    k_max <- safe_k_for(n_obs, n_smooth)
    f_safe <- if (n_smooth > 0) cap_smooth_k(f, k_max) else f
    
    tryCatch({
      m <- if (n_obs > 100) {
        bam(f_safe, data = data_clean, family = betar(link = "logit"),
            method = "fREML", select = TRUE, discrete = TRUE)
      } else {
        gam(f_safe, data = data_clean,
            family = betar(link = "logit"), method = "REML",
            select = TRUE)
      }
      environment(m$formula) <- environment()
      m
    }, error = function(e) {
      message(paste("Model", name, "fail in", segment_name,
                    "using betar:", e$message, "→ testing quasibinomial"))
      tryCatch({
        m2 <- gam(f_safe, data = data_clean,
                  family = quasibinomial(link = "logit"), method = "REML",
                  select = TRUE)
        environment(m2$formula) <- environment()
        m2
      }, error = function(e2) {
        message(paste("Model", name, "also failed with quasibinomial in", segment_name, ":", e2$message))
        return(NULL)
      })
    })
  })
  names(fits) <- names(formulas_cb)
  
  fits <- fits[!sapply(fits, is.null)]
  
 rank_def <- vapply(fits, function(m) m$rank < length(coef(m)), logical(1))
  excluded <- names(fits)[rank_def]
  if (length(excluded)) {
    message("Excluded as rank-deficient in ", segment_name, ": ",
            paste(excluded, collapse = ", "))
    fits <- fits[!rank_def]
  }
  
  stats <- lapply(names(fits), function(name) {
    m <- fits[[name]]
    s <- summary(m)
    data.frame(
      Model = name,
      AIC = tryCatch(AIC(m), error = function(e) NA),
      DevianceExplained = s$dev.expl,
      R2_Adj = s$r.sq,
      EDF = sum(m$edf),
      Segment = segment_name,
      stringsAsFactors = FALSE
    )
  })
  
  stats_df <- bind_rows(stats)
  
  if (nrow(stats_df) > 0) {
    
    stats_df <- stats_df %>%
      mutate(
        deltaAIC = AIC - min(AIC, na.rm = TRUE),
        weight = exp(-0.5 * deltaAIC) /
          sum(exp(-0.5 * deltaAIC), na.rm = TRUE)
      ) %>%
      arrange(AIC)
    
  }
  
  if (nrow(stats_df) > 0) {
    p_delta <- ggplot(stats_df, aes(x = reorder(Model, deltaAIC), y = deltaAIC)) +
      geom_col(fill = "steelblue") +
      geom_hline(yintercept = 2, linetype = "dashed", color = "red") +
      coord_flip() +
      labs(title = paste("ΔAIC by model -", segment_name),
           subtitle = "Dashed line = ΔAIC = 2 (competitive threshold)",
           x = "Model", y = "ΔAIC") +
      theme_minimal() +
      theme(legend.position = "bottom")
    
    p_weight <- ggplot(stats_df, aes(x = reorder(Model, -weight), y = weight)) +
      geom_col(fill = "darkgreen") +
      coord_flip() +
      labs(title = paste("AIC weights by model -", segment_name),
           subtitle = "Relative probability each model is best",
           x = "Model", y = "AIC weight") +
      theme_minimal()
    
    plots <- list(delta = p_delta, weight = p_weight)
  } else {
    plots <- NULL
  }
  
  return(list(fits = fits, stats = stats_df, plots = plots,
              excluded = excluded))  
}

extract_combined_stats <- function(best_obj, panel_name,
                                   alpha = 0.05, p_floor = 1e-4) {
  
  fmt_p <- function(p) ifelse(p < p_floor, "<1e-04", sprintf("%.2g", p))
  
  model <- best_obj$fit
  sm    <- summary(model)
  av    <- anova(model)
  
  ## Term-level p-values (s(age) excluded)
  pt_tab <- av$pTerms.table
  p_par  <- if (!is.null(pt_tab) && NROW(pt_tab) > 0)
    setNames(pt_tab[, "p-value"], rownames(pt_tab)) else numeric(0)
  st_tab <- sm$s.table
  st_cl  <- st_tab[rownames(st_tab) != "s(age)", , drop = FALSE]
  p_smo  <- setNames(st_cl[, "p-value"], rownames(st_cl))
  
  p_all  <- c(p_par, p_smo)
  p_all  <- pmax(p_all[!is.na(p_all)], 0)
  sig    <- p_all[p_all < alpha]
  
  sig_terms <- if (length(sig))
    paste0(names(sig), " (p=", fmt_p(sig), ")",
           collapse = "; ") else "Not significant"
  climate_p <- if (length(p_all)) min(p_all) else NA_real_
  
ptab  <- sm$p.table
  contr <- ptab[rownames(ptab) != "(Intercept)", , drop = FALSE]
  contr <- contr[!is.na(contr[, 4]) & contr[, 4] < alpha, , drop = FALSE]
  sig_contr <- if (NROW(contr))
    paste0(rownames(contr), " (", sprintf("%.2f", contr[, 1]),
           ", p=", fmt_p(contr[, 4]), ")",
           collapse = "; ") else "none"
  
  data.frame(
    Panel                = panel_name,
    Model                = best_obj$best_model,
    AIC                  = round(AIC(model), 3),
    DevianceExplained    = round(sm$dev.expl, 3),
    R2_Adj               = round(sm$r.sq, 3),
    SignificantTerms     = sig_terms,
    Climate_p            = climate_p,
    Climate_p_label      = if (is.na(climate_p)) "NA" else
      fmt_p(climate_p),
    SignificantContrasts = sig_contr,
    EDF_Terms            = paste0(rownames(st_tab), " (EDF=",
                                  round(st_tab[, "edf"], 2), ")", collapse = "; "),
    stringsAsFactors     = FALSE
  )
}

  m    <- best_models[[site]]
  idx  <- grep("^Thermal", names(coef(m)))
  b    <- coef(m)[idx]
  V    <- vcov(m)[idx, idx, drop = FALSE]
  lev  <- levels(droplevels(m$model$Thermal))                 # reference first
  w    <- as.numeric(table(factor(m$model$Thermal, levels = lev))) / nrow(m$model)
  A    <- t(sapply(lev, function(l) as.numeric(names(b) == paste0("Thermal", l))))  # level -> coef
  Cm   <- A - matrix(colSums(w * A), nrow(A), ncol(A), byrow = TRUE)                 # centring

check_temporal_independence <- function(mod) {
  # Extraer residuales tipo pearson
  res_raw <- residuals(mod, type = "pearson")
  if (is.list(res_raw)) res_raw <- unlist(res_raw)
  res_raw <- as.numeric(res_raw)
  
  # AR(1) coeficiente
  phi <- cor(res_raw[-1], res_raw[-length(res_raw)])
  
  # Durbin–Watson
  dw <- lmtest::dwtest(res_raw ~ 1)
  
  # Ljung–Box
  lb <- Box.test(res_raw, lag = 10, type = "Ljung-Box")
  
  list(
    phi_AR1 = phi,
    DW_stat = dw$statistic,
    DW_pval = dw$p.value,
    LB_stat = lb$statistic,
    LB_pval = lb$p.value,
    res_raw = res_raw
  )
}
