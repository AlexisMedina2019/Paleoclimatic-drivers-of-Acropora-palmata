# Florida-proximal temperature records (comparison with the 0–30°N anomaly)

Used only in Supplementary Material 1, Section 4.5.1 (Temperature), to test whether the regional temperature series (Kaufman et al. 2020, CPS 0–30°N) describes temperature change near the Florida reef tract. They are not model predictors.
